# 课程来源与取舍

来源为用户提供的本地课程目录：`用户提供的《课堂-学术裁缝从入门到精通》课程材料`。以下页码为 PDF 物理页码，从 1 开始。此文件是方法提炼，不是课程原文转载，也不是待研究领域的论文证据。

| 资料 | 使用位置 | 提炼为 Skill 的方法 |
| --- | --- | --- |
| 21学术裁缝的本质.pdf | 第 1–2 页 | 用 A+b+c 表达基准与模块的组合 |
| 22如何阅读论文.pdf | 第 4–5 页 | 从引言定位方法，再查方法与实验；需要采用的模块应精读 |
| 23如何拆分论文.pdf | 第 1–3 页 | 结合摘要、框架、章节和消融区分基准与模块 |
| 24定基准模型.pdf | 第 1–4 页 | 完整论文方法也能作为基线；关注复现与任务适配 |
| 25定学术模块.pdf | 第 1–3 页 | 模块可来自通用、本领域或相近领域；迁移需要理解作用 |
| 27学术裁缝实操.pdf | 第 1–3 页 | 按基准的数据流决定接入位置，记录模块适配变化 |

课程中的模块数量、近期年份及一周复现等经验不设为固定门槛。基线选择以用户资源和研究问题为准。

工程补充：语义/接口兼容、版本和来源记录、保留未知、用户选择或明确授权代选。这些是让组合可执行、可追踪的要求，不声称课程完整规定了这些细节。

不采用的课程说法：性能提升自动等于创新；通过轻微改名将借鉴变为原创；按有利方向选择论文值或复现值。所有借鉴持续注明来源，比较口径保持一致。
