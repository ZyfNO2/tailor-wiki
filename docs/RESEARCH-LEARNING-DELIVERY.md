# 研究与学习能力交付

2026-10-27，按用户选中的六项类比能力实施。

| 能力 | 实现位置 |
| --- | --- |
| 研究目标与缺口对齐 | academic-tailor：目标—依据—表达/证据/方法缺口—下一步 |
| 论文/代码导学 | 新 research-guide：阅读路径、按需讲解、练习和复练 |
| 答辩/组会追问 | research-story：按请求一次一问、基于回答反馈 |
| 实验复盘 | experiment-design：尝试、观察、失败、解释和下一步 |
| 同一证据多种表达 | research-story：简版故事、组会提纲、开题摘要方案 |
| 研究进度回顾 | experiment-design：读取实际文件，列已交付/受阻/待验证/下一步 |

导学接入独立安装器、分发与本地 guide 意图。没有强制总流程，没有新增 Team 或 UI；auto-research 仍待单独实施。个人练习答案不默认被意图入口读取、不默认回流科研 Wiki。原四 Skill 名保持兼容。

验证：五个 quick_validate 通过；36 项工程测试通过，包括五 Skill 分发/安装和导学独立路由、个人练习不默认摄入。首轮分发测试因缺少 fflate 无法加载，保留错误记录；npm ci --ignore-scripts 按锁文件安装依赖后原测试全量通过。未通过修改断言隐藏依赖错误。

边界：这是 Skill 指令、安装/路由与分发实现，工程测试不证明真实模型的导学/答辩质量；尚未使用新版执行真实六项场景。用户的 ds-flow-test 和论文未修改，未 push，旧包未覆盖。
